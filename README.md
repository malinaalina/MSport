# Приложение студии йоги и фитнеса

Android-приложение для управления расписанием тренировок

## Стек технологий

*   **Язык**: [Kotlin](https://kotlinlang.org/)
*   **UI**: [Jetpack Compose](https://developer.android.com/jetpack/compose)
*   **Навигация**: [Navigation 3](https://developer.android.com/guide/navigation/navigation-3) 
*   **Внедрение зависимостей**: [Dagger 2](https://dagger.dev/)
*   **Сеть**: [Retrofit](https://square.github.io/retrofit/) + [OkHttp](https://square.github.io/okhttp/)
*   **Архитектура**: Clean Architecture
*   **Статический анализ**: [Detekt](https://detekt.dev/)

## 🛠 Архитектура проекта

Проект разделен на модули для обеспечения масштабируемости и разделения ответственности:

*   **`:app`**: Точка входа, конфигурация Dagger и глобальная навигация.
*   **`:core`**: Общие компоненты.
    *   `:core:data`: Реализация репозиториев и локальное хранение сессий.
    *   `:core:domain`: Бизнес-логика и интерфейсы репозиториев.
    *   `:core:model`: Общие data-классы.
    *   `:core:network`: Настройка Retrofit и API-интерфейсы.
    *   `:core:designsystem`: Общая визуальная тема и UI-компоненты.
*   **`:feature`**: Функциональные модули.
    *   `:feature:auth`: Регистрация по номеру телефона, СМС-верификация и ПИН-код.
    *   `:feature:workout`: Расписание и личные тренировки.

## 📱 Основной функционал

1.  **Авторизация**:
    *   Ввод номера телефона.
    *   Верификация через 5-значный СМС-код.
    *   Установка и вход по 4-значному ПИН-коду.
    *   Сохранение сессии (автоматический переход к ПИН-коду при повторном запуске).

2.  **Расписание**:
    *   Просмотр занятий на неделю.
    *   Навигация по неделям (вперед/назад).
    *   Выбор конкретной даты.

3.  **Личные тренировки**:
    *   Список занятий, на которые записан пользователь.

4.  **Детали занятия**:
    *   Подробная информация: зал, преподаватель, описание, форма одежды.
    *   Возможность записаться на занятие в один клик.

## ⚙️ Настройка окружения

### Сетевое соединение
По умолчанию приложение настроено на локальный сервер:
`http://10.0.2.2:8080/` (адрес хост-машины для эмулятора Android).
